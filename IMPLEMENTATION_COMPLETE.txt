🚀 HOW TO USE
═════════════════════════════════════════════════════════════════════════════

QUICK START (30 seconds):
1. Double-click: run-backend.bat
2. Double-click: run-frontend.bat
3. Open browser: http://localhost:5173
4. Go to: Disease Prediction → Image Analysis
5. Upload image and click "Analyze"

DETAILED STEPS:
1. Ensure both servers are running:
   └─ Backend: http://localhost:5000 (verify by opening in browser)
   └─ Frontend: http://localhost:5173 (verify it loads)

2. Navigate to Disease Prediction:
   └─ Option A: Click Features dropdown in navbar
   └─ Option B: Click Disease Prediction card on home
   └─ Option C: Direct URL: /disease-prediction

3. Select Image Analysis Mode:
   └─ Click "📸 Medical Image Analysis" button

4. Upload Medical Image:
   └─ Drag-and-drop OR click to upload
   └─ Supported: JPG, PNG, GIF, WebP, TIFF (max 10MB)
   └─ Image preview displays automatically

5. Analyze Image:
   └─ Click "🔬 Analyze Image" button
   └─ Wait 1-2 seconds
   └─ Review detailed medical report

6. Review Results:
   └─ Image analysis details (pixel & color data)
   └─ Risk assessment (urgency level, confidence)
   └─ Disease predictions (top 3 with confidence scores)
   └─ Treatment recommendations
   └─ Diagnostic tests needed
   └─ Recovery timeline
