📡 API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════

1. GET /api/risk-dashboard/analysis
   Response: Complete risk analysis with all metrics
   Parameters: period (week/month/year), userId

2. GET /api/risk-dashboard/alerts
   Response: Current health alerts
   Parameters: userId

3. GET /api/risk-dashboard/history
   Response: Historical risk data over time
   Parameters: userId, startDate, endDate

4. GET /api/risk-dashboard/recommendations
   Response: Personalized health recommendations
   Parameters: userId, riskLevel

5. POST /api/risk-dashboard/compare
   Response: Risk score comparison
   Body: userId, startDate, endDate

6. POST /api/risk-dashboard/report
   Response: Comprehensive report
   Body: userId, format
